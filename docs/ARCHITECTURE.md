# 架构说明

```text
温湿度/门磁/定位传感器
          ↓ MQTT/HTTP
      设备接入与去重
          ↓
     冷链领域服务 ─→ 阈值规则 ─→ 告警与处置
          ↓                         ↓
  MySQL + 时序数据库          通知/工单适配器
          ↓
     批次合规报告与追溯
```

当前实现用 JSON 保存完整快照，用事件编号保证采集幂等，并对同类未关闭告警进行聚合。企业部署建议遥测写入时序数据库、业务主数据写入 MySQL，告警事件通过消息队列传递；报告生成使用只读数据副本。

严重告警必须处置后才能签收是领域不变量，不应由前端绕过。
